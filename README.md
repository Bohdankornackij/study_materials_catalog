# StudyHub — лабораторна робота №3

Flutter-застосунок «Каталог навчальних матеріалів», варіант №6.
Реалізовано всі 13 макетів із Figma. Реєстрацію, зміну пароля та редагування профілю додано в тому самому стилі для виконання вимог лабораторної.

## Запуск в Android Studio

1. Відкрити саме папку `study_materials_catalog`, де лежить `pubspec.yaml`.
2. Обрати Android-емулятор Pixel 9 Pro або підключений телефон.
3. Запустити `lib/main.dart` кнопкою Run. Після вже запущеної старої версії виконати Hot Restart.
4. Натиснути Get started. Екран Loading автоматично переходить до входу.
5. Для демонстраційного входу залишити `student@lpnu.ua` / `password123` і натиснути Sign in.
6. Пароль `1234` демонструє стан помилки, як на четвертому макеті Figma.

З термінала в папці проєкту:

```text
flutter pub get
flutter run
```

  models/

Стан неправильного пароля є частиною екрана входу. Меню дій і підтвердження видалення показуються через `showModalBottomSheet` і `showDialog`, відповідно до макетів. Їхні віджети також винесені в окремі файли.

## Як працює код

Використано стандартні `StatelessWidget`, `StatefulWidget`, `Scaffold`, `Column`, `Row`, `Container`, `TextField`, `ListView` та `SizedBox`.

Переходи виконуються через `Navigator.push`, `MaterialPageRoute` і `Navigator.pop`. Новий курс або матеріал повертається з форми через `Navigator.pop(context, результат)`. Батьківський екран додає результат до списку та викликає `setState`. Для входу й виходу використано `pushAndRemoveUntil`, щоб користувач не повертався до попереднього облікового запису кнопкою «Назад».

Об’єкти в `models/catalog.dart` є звичайними класами Dart. Додаткових бібліотек керування станом, маршрутизації та авторизації немає.

## Демонстраційний функціонал

- Пошук дисциплін за назвою курсу або матеріалу.
- Нижні вкладки Courses, Materials, Profile; Materials показує записи всіх дисциплін.
- Створення дисципліни з описом та кольоровим маркером.
- Перегляд матеріалів, згрупованих за темами.
- Додавання та редагування конспектів, посилань і назв файлів.
- Видалення тільки після підтвердження; Cancel залишає запис у списку.
- Перегляд та редагування імені, прізвища й email.
- Форми реєстрації, входу, відновлення і зміни пароля.
- Елементи інтерфейсу фото профілю, синхронізації та завантаження файлу.

Серверна бізнес-логіка не підключена. Дані існують лише в пам’яті й скидаються після перезапуску/виходу. Листи не надсилаються, пароль не змінюється в реальному обліковому записі, файли не завантажуються, Firebase не підключено. Для таких дій показується демонстраційне повідомлення.
